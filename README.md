**Civic Tech & Emerging Tech Data Analytics Assessment**
A comprehensive data analytics project featuring secondary data curation, inferential statistical hypothesis testing, and advanced Natural Language Processing (NLP) techniques (Named Entity Recognition, Topic Modeling, and Transformer-based summarization).

**Project Overview**
This repository contains the complete solution to a Data Analyst technical assessment. The project is divided into three core domain areas:

- Civic Technology Secondary Data Curation & Insight Generation

- Statistical Analysis & Hypothesis Testing on Talent Survey Data

- Emerging Technologies NLP & Unsupervised Machine Learning Pipeline

_**Prerequisites**_
